# Сайт технической поддержки с интеграцией в Битрикс24

Проект для дипломной работы — одностраничный веб-сайт, позволяющий сотрудникам подавать заявки в техническую поддержку. Заявки автоматически создаются в CRM Битрикс24 в виде лидов. Реализована удобная форма, информационные блоки (популярные проблемы, полезные статьи, шаблоны заявок), а также интерактивные подсказки.

## 🚀 Возможности

- **Подача заявки**  
  Форма с полями «Имя», «Тема», «Описание». Валидация на клиенте и сервере.

- **Интеграция с Битрикс24**  
  При отправке форма создаёт лид в CRM через REST API (входящий вебхук). Ответственный менеджер назначается автоматически.

- **Информационные блоки**  
  - 🔥 *Популярные сегодня проблемы* — кликабельные карточки, при выборе которых поля формы заполняются автоматически.  
  - 📚 *Полезные статьи* — при нажатии открывается модальное окно с подробной инструкцией (защита данных, ускорение ПК, восстановление пароля).  
  - 📋 *Шаблоны заявок* — готовые формулировки для типовых обращений (замена картриджа, настройка почты, списание техники).

- **Уведомления**  
  Toast-сообщения об успешном создании заявки (с номером лида) или ошибке.

- **Современный UI**  
  Градиентный фон, анимированные карточки, эффекты размытого стекла, плавные переходы и адаптивная вёрстка.

- **Без перезагрузки страницы**  
  Отправка формы через AJAX (fetch), результат отображается без редиректа.

## 📁 Структура проекта

project/
├── index.php # Главная страница с формой, информационными блоками, JS-логикой и стилями
├── submit.php # Обработчик формы: валидация, вызов API Битрикс24, JSON-ответ
├── config.php # Конфигурация (URL вебхука, ID ответственного)
└── README.md # Документация проекта

Файл `config.php` исключён из индексации Git (рекомендуется добавить в `.gitignore`), так как содержит секретный URL вебхука.

## 🛠 Технологии

- **Frontend**: HTML5, CSS3 (Flexbox, Grid, анимации, backdrop-filter), JavaScript (Fetch API, DOM-манипуляции)
- **Backend**: PHP 7+ (cURL для запросов к REST API)
- **Интеграция**: Входящий вебхук Битрикс24 (права `CRM`)
- **Дизайн**: стеклянный морфизм, градиенты, анимации, иконки эмодзи, шрифт Inter

---

## ⚙ Требования

- PHP 7.4 или выше с расширениями:
  - `curl`
  - `json`
- Веб-сервер Apache (XAMPP, MAMP, OpenServer) или встроенный PHP-сервер (`php -S`)
- Активный портал Битрикс24 (можно облачный) с правами администратора для создания вебхука
