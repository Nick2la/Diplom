
# Сайт технической поддержки с интеграцией в Битрикс24

Проект для дипломной работы — одностраничный веб-сайт, позволяющий сотрудникам подавать заявки в техническую поддержку. Заявки автоматически создаются в CRM Битрикс24 в виде лидов. Реализована удобная форма, информационные блоки (популярные проблемы, полезные статьи, шаблоны заявок), а также интерактивные подсказки.

## 🚀 Возможности

- **Подача заявки**  
  Форма с полями «Имя», «Тема», «Описание». Валидация на клиенте и сервере.

- **Интеграция с Битрикс24**  
  При отправке форма создаёт лид в CRM через REST API (входящий вебхук). Ответственный менеджер назначается автоматически.

- **Информационные блоки**  
  - 🔥 *Популярные сегодня проблемы* — кликабельные карточки, при выборе которых поля формы заполняются автоматически.  
  - 📚 *Полезные статьи* — при нажатии открывается модальное окно с подробной инструкцией (защита данных, ускорение ПК, восстановление пароля).  
  - 📋 *Шаблоны заявок* — готовые формулировки для типовых обращений (замена картриджа, настройка почты, списание техники).

- **Уведомления**  
  Toast-сообщения об успешном создании заявки (с номером лида) или ошибке.

- **Современный UI**  
  Градиентный фон, анимированные карточки, эффекты размытого стекла, плавные переходы и адаптивная вёрстка.

- **Без перезагрузки страницы**  
  Отправка формы через AJAX (fetch), результат отображается без редиректа.

## 🛠 Технологии

- **Frontend**: HTML5, CSS3 (Flexbox, Grid, анимации, backdrop-filter), JavaScript (Fetch API, DOM-манипуляции)
- **Backend**: PHP 7+ (cURL для запросов к REST API)
- **Интеграция**: Входящий вебхук Битрикс24 (права `CRM`)
- **Дизайн**: стеклянный морфизм, градиенты, анимации, иконки эмодзи, шрифт Inter

## ⚙ Требования

- PHP 7.4 или выше с расширениями:
  - `curl`
  - `json`
- Веб-сервер Apache (XAMPP, MAMP, OpenServer) или встроенный PHP-сервер (`php -S`)
- Активный портал Битрикс24 (можно облачный) с правами администратора для создания вебхука

## 🧩 Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/support-site.git
   cd support-site
   ```

2. **Настройте конфигурацию**  
   Откройте `config.php` и укажите:
   ```php
   <?php
   return [
       'webhook_url'  => 'https://your-portal.bitrix24.ru/rest/1/xxxxxxxxxxxxx/',
       'responsible'  => 1,   // ID ответственного менеджера в Битрикс24
   ];
   ```
   > ⚠️ Файл `config.php` не должен попадать в публичный репозиторий. Добавьте его в `.gitignore`.

3. **Запустите сервер**
   - **Встроенный PHP-сервер**:  
     ```bash
     php -S localhost:8000
     ```
     Сайт будет доступен по адресу `http://localhost:8000`.
   - **XAMPP / OpenServer**: скопируйте папку проекта в `htdocs` (или `domains`), затем откройте в браузере `http://localhost/support-site/`.

4. **Откройте в браузере** `http://localhost:8000` (или ваш адрес) и протестируйте форму.

## 🔗 Настройка интеграции с Битрикс24

1. Зайдите в портал Битрикс24 → **Приложения** → **Разработчикам** → **Другое** → **Входящий вебхук**.
2. Нажмите **«Добавить входящий вебхук»**.
3. Дайте название (например, «Заявки с сайта»).
4. В правах обязательно отметьте **CRM (crm)**.
5. Сохраните и скопируйте полученную ссылку (формата `https://ваш-портал.bitrix24.ru/rest/1/секретный_код/`).
6. Вставьте эту ссылку в `config.php` в параметр `webhook_url`.
7. Укажите числовой ID сотрудника, который будет назначаться ответственным по умолчанию (можно посмотреть в карточке пользователя в Битрикс24).

После этого заявки из формы будут автоматически превращаться в лиды CRM.

## 📝 Использование

1. **Откройте сайт** — загрузится главная страница с популярными проблемами, статьями и формой.
2. **Выберите проблему** из раздела «Популярные сегодня проблемы» или «Шаблоны заявок» — поля заполнятся автоматически.
3. **Введите своё имя** (обязательно), при необходимости измените тему и описание.
4. **Нажмите «Отправить заявку»**. Появится индикатор отправки, а затем toast-уведомление с номером заявки (ID лида).
5. **Проверьте Битрикс24** — в CRM появится новый лид с заполненными полями:
   - Название = тема заявки
   - Описание = текст из поля + имя заявителя
   - Ответственный = указанный в `config.php`
6. **Читайте статьи** — клик на любую карточку раздела «Полезные статьи» откроет подробную инструкцию в модальном окне.
7. **Повторяйте** — форма очищается после отправки, можно подать новую заявку.
